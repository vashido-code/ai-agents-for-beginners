# Fashion Content Studio

Прототип услуги «цифровая фотосессия» для продавцов одежды на Wildberries и Ozon. Продавец присылает фото вещи (на вешалке, манекене или раскладкой) и получает архив: фото на AI-моделях и короткое видео, уже в форматах обеих площадок.

## Как это работает

```
фото одежды ──> примерка на фото моделей (personas/) ──> оператор выбирает лучшие
            ──> видео из выбранных фото ──> подгонка под WB и Ozon ──> проверка ──> zip
```

- **Примерка** надевает вещь на каждую подходящую модель из `personas/personas.json` (по категории: `top`, `bottom`, `dress`, `outerwear`).
- **Выбор оператором.** Видео — самый дорогой шаг, поэтому оно делается только из одобренных фото.
- **Видео** строится по промпту для категории (`studio/config.py`): медленный поворот, шаг, движение ткани.
- **Подгонка** без обрезки вещи: кадр вписывается в нужный формат поверх размытой копии себя. Фото 3:4 (900×1200), видео 9:16 для WB и 1:1 для Ozon. Если клип короче 6 секунд (минимум WB), он проигрывается вперёд и назад.
- **Проверка:** размеры и длительность каждого видео проверяются через `ffprobe`. Если фото пришлось увеличивать, в отчёте будет предупреждение.
- **Экономика:** `pack/manifest.json` считает себестоимость генераций, цену и маржу. Этот файл только для вас, в архив клиента он не попадает.

## Провайдеры генерации

| `--provider` | Что это | Когда использовать |
|---|---|---|
| `mock` | заглушка без ключей и видеокарты | проверить процесс, показать структуру пакета |
| `kling` | Kling API: Kolors virtual try-on + image-to-video | быстрый старт без своих GPU. Нужна оплата Kling (из РФ — через посредника) или агрегатор с совместимым API (`KLING_API_BASE`) |
| `comfyui` | свой ComfyUI с open-source моделями | независимость от зарубежных API: свой или арендованный GPU (Selectel, Cloud.ru, Immers.cloud) |

## Запуск

Нужны Python 3.10+ и `ffmpeg`.

```bash
cd examples/fashion-content-studio
pip install -r requirements.txt

# Всё сразу на заглушке (демо)
python -m studio run DEMO-01 my_dress.jpg --category dress

# Рабочий процесс оператора
python -m studio new SKU-123 shirt.jpg --category top
python -m studio photos SKU-123              # фото в jobs/SKU-123/photos/
python -m studio approve SKU-123 f_studio_slim,m_studio
python -m studio video SKU-123
python -m studio pack SKU-123                # jobs/SKU-123/SKU-123_pack.zip
python -m studio status SKU-123
```

Провайдер выбирается флагом `--provider` (ставится перед командой) или переменной `STUDIO_PROVIDER`:

```bash
export KLING_ACCESS_KEY=... KLING_SECRET_KEY=...
python -m studio --provider kling photos SKU-123
```

| Переменная | По умолчанию |
|---|---|
| `STUDIO_PROVIDER` | `mock` |
| `STUDIO_JOBS_DIR` | `jobs` |
| `STUDIO_PRICE_PER_LOOK_RUB` | `2000` |
| `KLING_API_BASE` | `https://api-singapore.klingai.com` |
| `KLING_TRYON_MODEL` / `KLING_VIDEO_MODEL` / `KLING_VIDEO_MODE` | `kolors-virtual-try-on-v1-5` / `kling-v2-1` / `std` |
| `COMFY_URL` | `http://127.0.0.1:8188` |

Проверка без ключей: `python -m unittest discover tests` (полный прогон на заглушке, ~45 с).

## Что проверено и что нет

- **Проверено:** весь процесс на `mock`, форматы и длительность на выходе, архив и отчёт. Клиенты Kling и ComfyUI проверены на поддельных локальных серверах: формат запросов, JWT, ожидание задачи, скачивание, ошибка при неверной привязке узлов.
- **Не проверено на реальных сервисах.** Пути API Kling и названия моделей взяты из публичной документации. Сверьте их в консоли Kling и начните с одного образа. Для ComfyUI нужно подставить свои графы (`workflows/README.md`).
- **Себестоимость** в `studio/config.py` (`COSTS_RUB`) — оценки. Замените их на свой реальный тариф.
- **Требования площадок** (`MARKETPLACES`) — по состоянию на 2026 год. Перед запуском сверьте их в кабинетах продавца.

## Чего пока нет

- Приёма заказов и оплаты: сейчас оператор получает фото от клиента (например, в Telegram) и запускает команды сам. Следующий шаг — Telegram-бот и ЮKassa.
- Удаления фона с фото вещи и автоматической оценки качества примерки: брак отсеивает оператор на шаге `approve`.
- Нескольких вещей в одном образе (верх + низ).
