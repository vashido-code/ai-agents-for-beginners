# Фото моделей (персоны)

Примерка надевает одежду клиента на базовое фото модели. Каждая запись в `personas.json` — один типаж: пол, размер, фон. Файлы фото кладите в эту папку (в git они не попадают, см. `.gitignore`).

| Поле | Значение |
|---|---|
| `id` | имя, которое вы пишете в командах (`approve SKU f_studio_slim`) |
| `file` | имя файла в этой папке |
| `fits` | для каких категорий подходит: `top`, `bottom`, `dress`, `outerwear` |
| `note` | заметка для себя |

## Какие фото подходят

- В полный рост или по колено, модель стоит прямо, руки не закрывают корпус.
- Простая однотонная одежда по фигуре, без крупных принтов: так примерка ошибается реже.
- Минимум 960×1280 (3:4). Меньше — пакет для маркетплейса предупредит об увеличении.

## Права на внешность

Используйте только фото, на которые у вас есть права:
- **AI-сгенерированные модели** (самый простой вариант: сгенерировать один раз и хранить как персону);
- стоковые фото с лицензией на коммерческое использование;
- собственные съёмки с подписанным согласием модели (model release).

Фото реальных людей из интернета брать нельзя.

В режиме `mock` недостающие фото заменяются серыми силуэтами, так что прототип работает и без них.
